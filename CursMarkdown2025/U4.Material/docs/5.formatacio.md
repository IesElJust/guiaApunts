## **Formatació de Codi**

Un dels aspectes més importants en la documentació tècnica és la presentació correcta del **codi font**. El tema **Material per Mkdocs** permet integrar fàcilment **formatació de codi** per a diversos llenguatges de programació, utilitzant extensions com **Pymdown Extensions** i el suport per a resaltar la sintaxi del codi i afegir numeració de línies.

A continuació, veurem com configurar-ho i utilitzar-ho al nostre lloc de documentació.

### **1. Instal·lació de les extensions per formatar el codi**

Per habilitar la formatació de codi amb resalta de sintaxi i numeració de línies, necessitem instal·lar l'extensió **Pymdown Extensions**, que inclou la funcionalitat de resaltar sintaxi amb **highlight** i altres eines útils per a blocs de codi.

1. **Instal·lació** de **Pymdown Extensions**:

   ```bash
   pip install pymdown-extensions
   ```

2. **Configuració al fitxer `mkdocs.yml`**:

   Un cop instal·lada l'extensió, afegim la configuració al fitxer `mkdocs.yml` per activar les extensions de **highlight** i **superfences**. La configuració bàsica seria la següent:

   ```yaml
   markdown_extensions:
     - pymdownx.highlight:
         linenums: true
     - pymdownx.superfences
   ```

   * `linenums: true` activa la numeració de línies per als blocs de codi.
   * **superfences** afegeix una sintaxi més flexible i potent per incloure fragments de codi en diferents formats.

### **2. Sintaxi per afegir blocs de codi**

Un cop configurat, podem afegir blocs de codi dins dels nostres fitxers Markdown. La sintaxi per crear blocs de codi és la següent:

````markdown
```language
# Aci el codi font
```
````

On **`language`** és el llenguatge de programació que vols resaltar. Per exemple, per mostrar codi Python, utilitzem:

````markdown
```python
def salutacio():
    print("Hola món!")
```
````

### **3. Exemple de formatació de codi amb resalta de sintaxi**

Considerem que volem afegir un fragment de codi Python al nostre document de documentació. La sintaxi seria:

```markdown
# Exemples de codi Python

A continuació es mostra un exemple de codi Python que imprimeix un missatge per pantalla:

```python
def salutacio():
    print("Hola món!")
````

````

Això generarà un bloc de codi amb resalta de sintaxi per a Python i, si tens la configuració de **linenums** activada, també afegirà la numeració de línies a l'esquerra del codi.

### **4. Formatació de codi amb altres llenguatges**

També podem utilitzar altres llenguatges de programació, com JavaScript, HTML, CSS, etc. A continuació, et mostrem alguns exemples:

- **JavaScript**:

   ```markdown
   ```javascript
   let missatge = "Hola món!";
   console.log(missatge);
````

````

- **HTML**:

```markdown
```html
<html>
  <body>
    <h1>Hola món!</h1>
  </body>
</html>
````

````

- **CSS**:

```markdown
```css
body {
    font-family: Arial, sans-serif;
}
````

````

### **5. Opcions de personalització addicional**

A més de la sintaxi bàsica per a blocs de codi, també podem personalitzar l'aspecte del codi a través de l'estil CSS o altres configuracions avançades. Algunes opcions addicionals inclouen:

1. **Afegir numeració de línies**: Si tens habilitada l'opció **linenums**, es mostrarà la numeració de línies al costat esquerre del codi.

Exemple de configuració al fitxer `mkdocs.yml`:

```yaml
markdown_extensions:
  - pymdownx.highlight:
      linenums: true
````

2. **Afegir resalts personalitzats**: Pots afegir regles CSS personalitzades per modificar l'aparença dels blocs de codi, com els colors de fons, la font, o l'amplada del bloc.

3. **Canviar el tema del codi**: Per canviar l'aspecte visual del codi, pots utilitzar una biblioteca com **highlight.js** o **prism.js** i configurar-ho al teu fitxer `mkdocs.yml`.

### **6. Consells i bones pràctiques**

* **Ús moderat**: Tot i que la formatació de codi és una part crucial de la documentació, intenta evitar posar massa codi dins d'una mateixa pàgina. Si tens fragments molt grans de codi, considera posar-los en fitxers externs.
* **Claritat en els exemples**: Assegura't que el codi sigui clar i fàcil de llegir. Afegeix comentaris als fragments per explicar què fa cada part del codi.
* **Tipus de codi**: Si el codi prové d'exemples que no són tan habituals, afegeix el llenguatge correctament a la sintaxi per assegurar que el resaltat es fa adequadament.
