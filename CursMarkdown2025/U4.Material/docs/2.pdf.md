## **Generació de Documents PDF**

Un dels avantatges més destacats del tema **Material per Mkdocs** és la capacitat de generar un **document PDF** de tot el lloc web creat amb Mkdocs. Això pot ser útil per distribuir la documentació de manera més accessible, o per generar una versió imprimible de la documentació en format PDF.

Per aconseguir-ho, utilitzarem el plugin **Mkdocs PDF Export**, que ens permet crear un PDF de tot el lloc web o d’una pàgina concreta, mantenint el disseny original i la jerarquia de contingut.

### **1. Instal·lació del plugin**

Per començar a utilitzar el plugin **Mkdocs PDF Export**, primer cal instal·lar-lo al nostre entorn virtual de Python mitjançant **pip**. Això afegirà el plugin necessari per exportar el PDF:

```bash
pip install mkdocs-pdf-export
```

### **2. Configuració al fitxer `mkdocs.yml`**

Un cop instal·lat el plugin, cal activar-lo al fitxer de configuració `mkdocs.yml`, que es fa servir per definir les opcions del nostre projecte.

Afegirem la configuració del plugin dins de la secció de `plugins`:

```yaml
plugins:
  - pdf-export
```

Aquesta configuració és molt senzilla i no requereix cap ajust addicional. Si vols personalitzar l’exportació de PDF amb altres opcions, el plugin permet afegir algunes configuracions opcionals, com ara la direcció de sortida o la configuració de les pàgines del PDF.

### **3. Generar el PDF**

Un cop configurat el plugin, el següent pas és generar el PDF del lloc complet. Aquest procés es fa mitjançant la línia de comandament de **Mkdocs**, amb la instrucció següent:

```bash
mkdocs pdf-export
```

Aquesta comanda generarà un arxiu **PDF** de tot el lloc web, mantenint l'estructura de seccions, sub-seccions, i la jerarquia de contingut que hem definit als nostres fitxers Markdown.

#### **4. Opcions del plugin**

El plugin permet algunes opcions per personalitzar l’exportació de PDF, com ara:

* **Configuració de la pàgina de portada**: Per definir una portada especial per al PDF.
* **Configuració de marges i mida de pàgina**: Per ajustar les dimensions de la pàgina o els marges.
* **Incorporació de recursos externs**: Com per exemple, imatges o fitxers CSS per personalitzar l’aspecte del PDF.

Per exemple, si vols personalitzar l’aspecte del PDF amb un arxiu de **CSS** personalitzat, pots afegir la ruta al fitxer dins del fitxer `mkdocs.yml`:

```yaml
plugins:
  - pdf-export:
      css: "path/to/custom_styles.css"
```

### **5. Exemple d'ús: generant un PDF**

Un cop configurat el plugin, el procés és força senzill. Considerem que tenim un projecte de documentació amb una estructura bàsica com aquesta:

```
project/
│
├── docs/
│   ├── index.md
│   └── introduction.md
├── mkdocs.yml
```

Quan executem la comanda `mkdocs pdf-export`, el sistema generarà un fitxer PDF que inclou **totes** les pàgines dins de la carpeta `docs/`, tal com es veurien en el lloc web.

### **6. Personalització avançada**

Si vols personalitzar el PDF més enllà de les opcions bàsiques, pots modificar l'exportació utilitzant el plugin **`pdf-export`**. Algunes opcions de configuració inclouen:

* **Mida de la pàgina**: Ajustar la mida de les pàgines del PDF (per exemple, A4, carta, etc.).
* **Personalització de la portada**: Si vols afegir una portada personalitzada, es pot especificar una imatge de portada.
* **Capçaleres i peu de pàgina**: Configurar capçaleres i peus de pàgina per a les diferents seccions.

Per exemple, una configuració més avançada pot veure's així:

```yaml
plugins:
  - pdf-export:
      cover: "docs/cover_image.png"
      page_size: "A4"
      header: "My Documentation Header"
```
